# AI Learning Game Project

We are building a cyberpunk-style AI Learning Game Platform.

Goal:
Make learning AI fun and beginner-friendly through gameplay, quests, progression, and interactive scenarios.

The game should feel like:

* Duolingo + RPG + Cyberpunk + AI Simulator

Core Gameplay:

* Lessons are missions
* Players gain XP and levels
* Energy system limits gameplay sessions
* NPC dialogue and AI scenarios
* Rewards and progression systems
* AI evolution system
* Unlockable worlds and skills

Target Audience:
People who want to learn AI but have little or no technical background.

Important Development Rules:

* Focus on FUN first
* Keep systems simple and modular
* Avoid overengineering
* Build small playable prototypes first
* Prioritize gameplay feel over complex architecture

UI Direction:

* Cyberpunk
* Futuristic
* Neon glow
* Dark mode
* Clean modern UI

Tech Stack:

* Next.js
* Tailwind CSS
* Supabase
* Vercel

Development Philosophy:
Always build step-by-step.
Create playable systems before adding complexity.
